# Contracts: React MDX Presentation Renderer

**Date**: 2025-12-25  
**Feature**: 001-react-mdx-renderer

This directory contains API contracts for the React MDX renderer system.

## Contents

1. [components.ts](components.ts) - React component prop interfaces

These contracts serve as the source of truth for:
- TypeScript component development
- Python MDX generator implementation
- Validation of input/output formats
