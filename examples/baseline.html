The LLM Shift: "Composers"

Large Models are now a Unified Knowledge Base with a reasoning interface.

From Building...

  • Constructing models from scratch.
  • Focus on Model Accuracy.
  • Linear pipelines.

To Composing...

  • Prompting & Orchestration.
  • Focus on User Experience & Iteration Speed.
  • Multi-modality integration.
"We shift from micro-optimization to prompt strategy and workflow design."

The Blurring of Roles

The gap between Scientist and Engineer is closing.

The Scientist

Previously: Focus on Model Accuracy.
Now: Explores boundaries of base models, orchestrates features, focuses on reliability/robustness.

The Engineer

Previously: System throughput & latency.
Now: Designs validation, automatic evaluation loops, and integrates adaptive systems.

Outcome: Human-AI Co-Creation

Combating Hallucinations & Error Accumulation

LLMs struggle with long-context memory and consistency. The solution is Architecture.

Planner - Executor Pattern

The Planner (LLM)

High-level reasoning. Decides "Move forward 3 steps."

The Executor (Code/Guard)

The "Guardian." Actually maintains state/coordinates. Prevents the LLM from "forgetting" where it is.

"Real-time feedback and verification limits error accumulation."

High ROI Skills for Developers

Where should you invest your learning time now?

  1. Precise Problem Definition

    Defining the scope is harder than solving the code. LLMs are bad at scoping.

  2. Robust Evaluation & Tuning

    Building automated feedback loops to trust the system.

  3. Cross-Domain Combination

    Single-domain depth is less sufficient. The value is in connecting domains.

Where Humans Are Still Critical

1. Performance Tuning

LLMs (Copilot/Claude) are currently poor at low-level optimization (C++ intrinsics, memory caching, battery efficiency).

2. Identifying Correct Scope

Example: An LLM can optimize a function to run 20% faster, but a Human realizes the function shouldn't be called 38 times a second in the first place.

Final Career Advice

"Make every step solid."

✅ If you write code, make sure it works as best as it can.

✅ If you ask a question, ensure you truly understand the answer. If you don't understand the answer, you haven't gained knowledge.

✅ Retire before AI takes over? (Joking!)
Real advice: Adapt. Just as manual testers evolved into automation engineers, developers must evolve into AI orchestrators.

Summary

Define complex problems.
Build robust evaluation loops.
Orchestrate, don't just implement.
