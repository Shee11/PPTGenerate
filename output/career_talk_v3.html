From model-centric to system-centric LLM work

  • Large models = unified knowledge base + reasoning interface
  • Shift from bespoke training pipelines to prompt-based composition
  • Lightweight orchestration glues models, tools, and context together
  • Focus moves from raw model accuracy to user experience
  • Iteration speed becomes as important as benchmark scores
  • Micro‑optimization now = prompt strategy and workflow design
  • Design agent architectures, not just low‑level algorithms
  • Integrate multi‑modality: text, code, images, tools
  • Think about how components invoke models and tools reliably
  • Less time on training pipelines, more on system behavior
  • Goal shifts from benchmark performance to reliability in production
  • Build robustness, clear failure modes, and feedback loops
  • Prompt tuning helps but is not a silver bullet
  • Use planner–executor separation for multi‑step workflows
  • Deterministic executors and external verification stop error accumulation

Reliability as the new quality bar

  • LLM era: focus on reliability
  • Beyond benchmarks to robustness
  • Clear failure modes and feedback loops
  • Automatic refinement for fast iteration
  • Iterative prompt tuning, not silver bullet
  • Target ~90% typical cases first
  • Find ~10% edge cases, refine prompts
  • Complement with external verification
  • Planner–executor separation required
  • LLM = high-level planner of steps
  • Actions in structured, non-LLM format
  • Deterministic executors validate each step
  • Real-time feedback, replanning, retries
  • Stops small errors compounding to garbage
