How AI work has shifted

A decade of AI career shifts

We’ll use my path from 2011→2021—vision, mobile, generative, LLMs—to frame today’s AI career choices.

Goal: clearer choices for your next move

Revisiting the traditional AI pipeline

Traditional AI pipeline: linear and siloed

  • Collect and curate data (data engineers)
  • Select or design model architecture
  • Train and tune for accuracy, iterate
  • Deploy, optimize latency, measure impact

Clear role boundaries but slow, expensive, and repeatedly rebuilt infrastructure and evaluation.

Sets up why some old optimization habits now deliver lower career ROI.

From training models to orchestrating LLM-powered experiences

Traditional AI Era

LLM / Large Model Era

  • Primary: model accuracy, standalone models
  • Linear pipeline: data → training → deploy
  • Fixed roles: data, model, systems, product
  • Optimize architectures, training micro-gains
  • Reinvent infra, eval, optimization stacks
  • Separate vision, text, other modalities
  • Primary: UX, reliability, iteration speed
  • Composable, orchestration-driven workflows
  • Blurry roles around app delivery, orchestration
  • Optimize prompts, workflows, agents, eval loops
  • Heavy reuse of powerful base models
  • Toward multimodal text, vision, audio integration
  • LLMs = unified knowledge + reasoning interface
  • Shift: training → orchestration, UX, iteration
  • Start from user problem and experience
  • Compose models, tools via prompts and agents
  • Design robust, multimodal workflows and tools
  • Embed automated eval and feedback loops
  • Continuously tune UX and iteration speed

Career shift: invest in prompting, orchestration, evaluation loops, and product-focused UX thinking.

Where engineering ROI really comes from now

High-ROI skills in the LLM era

1. Precise problem definition

Define problems beyond current model capabilities; imagine what is truly useful for users.

2. Evaluation and tuning loops

Build robust evaluation, automated validation, and telemetry-driven feedback to accelerate iteration.

  • Thoughtful cross-domain combinations of tools and modalities
  • Integrate systems with adaptive feedback loops
  • Prioritize features over tiny accuracy gains

Shift focus from last-fraction accuracy to evaluation, integration, and cross-domain problem solving.

From prompts to architectures: shared responsibility

Roles blur in the LLM era

  • Applied scientists: push model boundaries
  • Orchestrate base models into features
  • Share product delivery with engineers
  • Engineers: system design, stability
  • Integrate large models into systems
  • Collaborate tightly with scientists
  • Prompt tuning ≠ silver bullet
  • Use planner–executor architectures
  • Executor verifies, planner adjusts
  • Architect for hallucination control

Career takeaway: reliability is a system design problem both engineers and scientists own.

Stay valuable alongside stronger AI

Play to strengths LLMs still lack

  • Scope problems before optimizing
  • Fix system or pipeline issues first
  • Avoid pointless local micro-optimizations
  • Lean into low-level performance work
  • C++ intrinsics, cache-aware tuning
  • LLMs still weak at this layer
  • Use one spec as source of truth
  • Treat LLM as multi-artifact translator
  • Continuously refine AI tool workflow

Focus your growth on problem scoping, low-level performance, and evolving AI-augmented workflows.

Mindset and habits

Mindset and habits for AI‑resilient careers

  • Continuously evolve with the industry
  • Be willing to become a beginner again
  • Actively learn and adopt AI tools
  • Leverage AI to build user‑centric systems
  • Focus on evolving skills, not titles
