Baseline: traditional AI before LLMs

Traditional model‑centric AI world

Linear pipeline workflow

  • Train and tune for accuracy

From prompt tuning to planner–executor reliability

Building reliable LLM systems

  • Define prompt for ~90% cases
  • Collect real edge and failure cases
  • Refine prompt to cover edge cases
  • Repeat until remaining failures acceptable
  • Prompt tuning reduces hallucinations, errors
  • Not a silver bullet for reliability
  • Multi-step workflows still accumulate errors
  • LLM planner proposes multi-step plans
  • Executor layer runs steps, tracks state
  • Executor validates steps in real time
  • On failure, trigger retries or alternatives
  • Persist critical state outside the LLM

Key challenge: error accumulation across steps; planner–executor with real-time verification limits it.

Roles Converging, Skills Shifting

Engineers vs Applied Scientists

High-ROI Skills to Build

Engineer

  • Deliver stable, scalable systems.
  • Focus: system design, integration.
  • Overlap: uses AI tools, experiments.
  • Work: pipelines, LLM integration, reliability.

Applied Scientist

  • Push model capabilities, enable features.
  • Focus: model behavior, orchestration.
  • Also cares about product usefulness.
  • Work: new LLM features, prompts, robustness.
Modern base models narrow the gap: both aim to deliver useful products.
  • Move beyond single-domain depth; combine tools, domains.
  • Shift from tiny accuracy gains to telemetry and adaptive loops.
  • 1) Precise problem definition with data feedback.
  • 2) Robust evaluation, automatic evaluation, feedback loops.
  • 3) Cross-domain combination to solve complex problems.

Both roles evolve toward integrating systems, telemetry, and evaluation to accelerate iteration.

Invest in skills that define problems well, measure outcomes, and connect domains.

Entry & mid-level dev takeaway: specialize less in silos, more in systems + evaluation.

Human edge and staying relevant

Where humans still have an edge

  • Low-level tuning: C++, memory, cache
  • Whole-system problem scoping and impact
  • Local speedups can miss real bottlenecks
  • Pipeline call frequency can dominate cost
  • Evolve with LLMs, stay curious
  • Embrace automation, expand your skill set

LLMs will surpass us in many areas—our edge is system thinking, performance, and adaptability.

How Chao actually uses AI tools

Chao’s AI‑augmented workflow

  • Write an abstract/spec as source of truth
  • Set up MCP for PowerPoint, Word, Mermaid
  • Use LLMs as translators to generate slides, docs, diagrams
  • Iterate on the spec and regenerate everything as needed
  • Adopt tools only for concrete tasks

  • Focus on patterns, not every new tool or paper

Takeaway: Treat specs as your single source of truth and adopt tools task‑first.
