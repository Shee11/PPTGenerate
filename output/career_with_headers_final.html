Adapting a Tech Career

Tech careers follow waves: vision, deep learning, cloud, then LLMs and agents.

Career Principle

Follow technology waves

Foundation: Computer Vision

Starting in computer vision builds a strong foundation in applied machine learning.

Start: vision

  • Applied ML
  • Real data
  • APIs
  • Products

Working on products like Face API builds experience deploying models into real applications.

Inflection: Deep Learning

Moving to deep learning requires new modeling techniques and modern ML tooling.

Shift: deep learning

  • Neural nets
  • GPU training
  • Modern frameworks
  • End-to-end models

This shift changes focus from classical methods to representation learning and more complex models.

Inflection: Cloud & Scale

Transitioning into cloud services introduces distributed systems, scalability, and reliability.

Shift: cloud systems

  • Scalability
  • Reliability
  • Distributed systems
  • Cloud platforms

Learning scalability shifts work from model-centric tasks to platform and service-centric thinking.

Inflection: LLMs & Agents

Working with large language models shifts development toward orchestrating intelligent systems.

Wave: LLMs, agents

  • Prompting
  • Orchestration
  • Probabilistic thinking
  • Experimentation

Exploring how LLMs change development requires experimentation and adaptation to model behavior.
