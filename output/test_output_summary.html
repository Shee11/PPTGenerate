From 2011→2021 vision work to today’s AI shift, your habits must evolve.

AI is rewriting tech careers

This talk: mindsets and daily practices to thrive in the new AI landscape.

The old AI world

Traditional AI: slow, linear pipeline

  • Linear handoff: data → model → training → deployment → impact
  • Rigid role ownership at every stage
  • Slow, expensive, heavy bespoke infrastructure
  • Great for accuracy, bad for learning speed

Takeaway: don’t blindly copy this linear, role-partitioned pattern into your AI career—optimize for learning speed and impact, not just accuracy.

Mindset: question slow, role-siloed pipelines when designing your own path.

Large models flipped the game

From models to LLMs

  • Start from powerful base model
  • Treat it as reasoning engine
  • Define problems via UX
  • Compose prompts, agents, tools
  • Optimize reliability and impact
  • Iterate with feedback loops

Career takeaway: win by problem definition, orchestration, and real user experience.

From single‑algorithm depth to problem‑shaping

New high‑ROI skills in the LLM era

  • Precise problem definition
  • Imagine products you’d actually use
  • Robust evaluation and tuning
  • Test usefulness, not just accuracy
  • Combine domains and tools
  • Depth alone is less sufficient

Quick test: Can you describe one genuinely useful LLM product for your own day?

Designing LLM Systems That Don’t Spiral

LLMs drift; systems catch them

  • Define prompt for ~90% cases
  • Test widely to expose failures
  • Encode constraints for edge cases
  • Iterate to shrink remaining ~10%
  • LLMs accumulate small errors
  • Prompt tuning reduces, doesn’t erase
  • Architectures must constrain each step
  • Verify outputs before they cascade
  • LLM plans goals and steps
  • Store steps as precise structured data
  • Executor code maintains real state
  • Retry or replan when execution fails
  • Feedback loop blocks catastrophic drift

Career takeaway: don’t trust raw LLM output—build constraints, checks, and structure.

Where humans still win

  • Deep, low-level performance work
  • Judgment on problem scope

LLMs struggle with C++ intrinsics, cache-aware tuning, and choosing the right system boundary.

Working with AI tools: single source of truth

Turn AI into leverage, not magic

  • Write one clear natural-language spec
  • Use AI as a translator from that spec
  • Generate slides, scripts, diagrams, starter code
  • Iterate by editing the spec only

A single, well-written spec becomes your source of truth for every artifact.

Apply this planner-executor pattern to future projects for consistent outputs.
