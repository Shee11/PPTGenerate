Practicing Problem Definition & Prompting

1 · Imagine Real Use
2 · Frame Broadly
3 · Draft Core Prompt
4 · Hunt Edge Cases

Start from a feature genuinely useful in daily work.

Include data feedback, human–AI interaction, not just metrics.

Cover ~90% common cases with one interaction pattern.

Collect failures; encode handling in prompts, workflows.

Planner–Executor Pattern

1 · Plan With LLM
2 · Store Structured Plan
3 · Deterministic Executors
4 · Verify, Retry, Replan
