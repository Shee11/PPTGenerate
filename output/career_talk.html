Translating skills into concrete LLM practices

How to work with LLMs effectively

  • Human–AI co‑creation is iterative
  • Multiple rounds, not one‑shot
  • Users and AI refine together
  • Prompt tuning is iterative
  • Start with general prompt (≈90%)
  • Collect failure and edge cases
  • Encode constraints and clarifications
  • Drive down last 10% failures
  • Prompt tuning alone not enough
  • Multi‑step workflows accumulate errors
  • Use planner–executor architectures
  • LLM plans; executors perform, verify
  • Feed outcomes back to planner

Career takeaway: treat LLM work as iterative design—prompt tuning, planner–executor, and human–AI co‑creation loops.
